# Himalaya Basin Analytics WebApp — Project Context

## 1. Project Overview

**Himalaya Basin Analytics WebApp** is a scientific geospatial web application built for climate, hydrology, cryosphere, and environmental analysis over the Himalayan basin region.

The application allows users to visualize, filter, compare, and analyze large-scale gridded environmental datasets such as ERA5, CMIP6, SPHY model outputs, MODIS snow/albedo products, discharge network data, uploaded NetCDF datasets, glacier boundaries, and basin/sub-basin geometries.

The core purpose of the app is to convert heavy scientific datasets into an interactive map-and-graph interface so scientists can explore spatio-temporal patterns without manually writing code for every analysis.

The app is designed as a **local-first scientific dashboard**, but it also has deployment support through a frontend/backend split.

## 8. Long-Term Hotspot Analysis

The app includes a long-term hotspot module.

Purpose:

To identify regions where the selected variable changes most strongly over time.

Backend logic:

- Group data by spatial point.
- Build annual mean series.
- Fit linear trend for each point.
- Compute slope per year.
- Compute total change.
- Compute trend strength.
- Classify hotspot level.

Hotspot outputs include:

- Points analyzed
- Hotspots identified
- Mean trend strength
- Max trend strength
- Percentile-based strength thresholds
- Top hotspot list
- Spatial hotspot map

Important idea:

A hotspot is not simply a high-value area. It is a region where the variable changes strongly over time.

Current outcome:

```text

```

Outputs:

```text

long_term_hotspot_band_differences.parquet
long_term_hotspot_metadata.json
long_term_hotspot_band_differences_metadata.json
```

Scripts:

```text
compute_era5_band_means.py
compute_band_differences.py
```

Scientific logic:

The ERA5 data is divided into 25-year bands:

```text
1951–1975
1976–2000
2001–2025
```

For each band, the mean of each variable is computed at each spatial point.

The app can show:

- Mean map for a selected band
- Difference between later band and earlier band

Formula:

```text
Difference = Mean_later_band - Mean_earlier_band
```

This helps identify long-term spatial change patterns.

## 11. Backend Technical Concepts

### Lazy Dataset Loading

The backend does not load everything at startup.

It indexes/loading datasets when requested.

This avoids heavy startup time.

---

### Year-Based Indexing

The selected year range controls which files are indexed.

Example:

```text
year_start=2011
year_end=2024
```

This improves performance for large datasets.

---

### Parquet Querying

Parquet is used because it is:

- Columnar
- Faster than CSV
- Smaller than CSV
- Better for repeated scientific queries
- Easy to filter by date/elevation/variable

---

### GeoTIFF Handling

Raster datasets are read using Rasterio.

The backend extracts:

- Raster values
- Latitude
- Longitude
- Date from filename
- Optional default elevation

---

### GeoParquet Handling

GeoParquet is used for vector/network spatial data such as discharge.

GeoParquet keeps geometry and attributes in a compact columnar format.

For visualization, heavy geometry can be converted to lightweight centroid records.

---

### Subregion Masking

For basin/glacier/subregion filtering, backend creates point-in-polygon masks.

This allows selecting only points inside a given polygon.

---

### NetCDF Ingestion

NetCDF ingestion uses:

- Xarray
- NetCDF4
- Pandas
- PyArrow

The backend detects spatial/time dimensions and converts numeric spatial variables into Parquet.

## 20. Scientific Computation Summary

### Basin Mean

For each selected date:

```text
mean_value = mean(variable values inside basin/elevation/subregion filters)
```

---

### Region Mean

For selected rectangle/subregion and year:

```text
region_mean(date) = mean(variable values inside selected spatial bounds)
```

---

### Elevation Filter

Only points satisfying:

```text
elev_min <= elevation_m <= elev_max
```

are included.

---

### Hotspot Trend

For each spatial point:

```text
annual_mean(year) = mean(values in that year)
```

Then fit:

```text
value = slope * year + intercept
```

The slope indicates direction and rate of change.

---

### Band Mean Outcome

For each 25-year band:

```text
band_mean = mean(variable over all dates in band at each spatial point)
```

---

### Band Difference

```text
difference = later_band_mean - earlier_band_mean
```
